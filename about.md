[Old News]{.newthought} is a curated digital humanities archive focused on preserving and showcasing 19th-century journalism. This platform offers clean transcriptions of fragile text along with direct access to physical newspaper clippings, enabling students and researchers to bridge raw primary prints with modern data sets.

## Open Source Pipeline

The text displayed across this archive is generated using a custom optical character recognition (OCR) pipeline built using [Tesseract](https://tesseractocr.org/){target="_blank" rel="noopener noreferrer"} and open-access AI tools.

The entire pipeline engine is open-source and public. You can view the code, report issues, or study the infrastructure layout directly at the [oldnews-OCR-pipeline GitHub Repository](https://github.com/victorelgersma/oldnews-OCR-pipeline){target="_blank" rel="noopener noreferrer"}. This repo also hosts the markdown texts appearing on this site.

## Source Verification

Every transcription hosted on this site maintains a direct link back to its material reference point. By utilizing the **'View Source'** button on any given entry, you can immediately review original photocopy clippings hosted by our image repository or visit their permanent records, such as at the British Newspaper Archive.
